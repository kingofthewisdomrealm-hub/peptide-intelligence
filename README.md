# PEPTIDE INTELLIGENCE

Evidence engine for peptides and GLP-1s — not a catalog, not a clinic.

Popularity does not raise a score. An animal tendon study is not a human injury trial. A July 2026 advisory-committee vote is not an FDA approval and is not a license to compound. A COA is not sterility. Two peptides studied separately are not a studied stack.

## App

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Evidence labels

| Label | Meaning |
|---|---|
| **FACT** | Measured in humans, regulators, or the published record |
| **INFERENCE** | Reasonable reading of that record |
| **EXPERT OPINION** | Clinician or scientist judgment, not a trial |
| **ANIMAL DATA** | Preclinical only — does not prove human benefit |
| **ANECDOTE** | Forums, influencers, clinics |
| **MARKETING CLAIM** | Seller language |
| **UNKNOWN** | Not established |
